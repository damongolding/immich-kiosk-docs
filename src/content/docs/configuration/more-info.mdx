## YAML Configuration

```yaml
more_info:
  display: true # show the more info overlay
  like_button_action: favorite # album, favorite or both [album, favorite]
  hide_button_action: tag # tag, archive, or both [tag, archive]
  show:
    asset_link: true
    qr_code: true
    rating: true
    like_button: true
    hide_button: true
```

## Show More Info

Enables the display of additional information about the current image(s)

<Settings 
    config="more_info.display"
    env="KIOSK_MORE_INFO_DISPLAY"

    defaultValue="true" />

## Like Button Action

Action(s) to perform when the like button is clicked. Supported actions are [favorite, album].

<Settings 
    config="more_info.like_button_action"
    env="KIOSK_MORE_INFO_LIKE_BUTTON_ACTION"
    url="more_info_like_button_action"
    urlOver={"http://{URL}?more_info_like_button_action=favorite"}
    value="[]string"
    defaultValue='["favorite"]' />

### Favorite (the default)

Set asset as a favorite inside Immich.

Example:

```yaml
like_button_action: favorite
```

### Album

Add asset to the "Kiosk Favorites" albums, which will be created if it doesn't exist.

Example:

```yaml
like_button_action: album
```

### Both

Marks the asset as a favourite and adds it to the 'Kiosk Favorites' album

Example:

```yaml
like_button_action: [favorite, album]
```

## Hide Button Action

Action(s) to perform when the hide button is clicked. Supported actions are [tag, archive].

<Settings
    config="more_info.hide_button_action"
    env="KIOSK_MORE_INFO_HIDE_BUTTON_ACTION"
    url="more_info_hide_button_action"
    urlOver={"http://{URL}?more_info_hide_button_action=tag"}
    value="[]string"
    defaultValue='["tag"]' />

### Tag (the default)

Tag asset with the "kiosk-skip" tag.

Example:

```yaml
hide_button_action: tag
```

### Archive

Set asset as archived inside Immich.

Example:

```yaml
hide_button_action: archive
```

### Both

Add tag and archive asset.

Example:

```yaml
hide_button_action: [tag, archive]
```
